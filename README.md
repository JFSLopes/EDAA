# Advanced Data Structures and Algorithms (EDAA)

A C++ prototype for multimodal routing on a transport network, with walking, bus, metro, and transfer connections. It also explores and benchmarks graph algorithms and data structures: Dijkstra and A* routing, Prim's algorithm, brute-force and heap-based priority queues, graph coloring, and Quadtree-based spatial indexing.

The [project report](report/edaa_report.pdf) explains the design, algorithms, and empirical results.
